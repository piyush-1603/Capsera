# Database Migrations

This directory contains the ordered PostgreSQL SQL migration files for CAPSERA.

## Migration Sequence

Migrations are executed in sequential order against `capsera_db` via the automated runner:

1. `001_identity_and_skills.sql` — Users, profiles (trainee/trainer), skills, and user-skill associations.
2. `002_courses_and_learning.sql` — Courses, lessons, learning resources, enrollments, and lesson progress.
3. `003_assessments_and_feedback.sql` — Assessments, questions, attempts, answers, and course feedback.
4. `004_certificates_and_announcements.sql` — Certificates, announcements, and administrative audit logs.

## Running Migrations

Execute using the project migration runner:

```bash
npm run db:migrate
```

To view migration execution status:

```bash
npm run db:status
```

## Guidelines

- All tables target **PostgreSQL 18.6+** using identity columns (`GENERATED BY DEFAULT AS IDENTITY`).
- Timestamps use `TIMESTAMPTZ` with UTC defaults (`CURRENT_TIMESTAMP`).
- Auditing uses PostgreSQL `JSONB` with a `GIN` index.
- All migrations are tracked in `schema_migrations` and executed inside isolated transactions.
